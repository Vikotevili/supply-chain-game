游戏 14 分钟过一天

730 天里你只需要动手几次

真实时间大约一周。把 820、旺季、停产日写进日历，比天天盯盘重要。

  1. 第 730 天

    立刻加产能 +20，目标 40 桶/天

    现在 20 桶/天远低于季节均值 38.8、峰值约 65。产能 90 天后（第 820 天）才上线，越晚买，高峰越接不住。现金支出 $1,000,000，账上仍剩约 $1,738,867，够付下一批生产。产能买了不能退，所以只加到均值略上方，不追峰值 65。

    点 Calopeia 工厂 → add capacity → 填入要新增的桶数（不是目标总数）→ 确认

  2. 第 730 天

    生产批量改为 200（1 整车）

    默认 150 不满整车，每桶运费 $100；整车 200 只要 $75。批量 200 时每桶边际贡献约 $218（卖价 1450 − 履约 150 − 制造 1000 − 运费 − 单批设置费摊销）。邮寄 $150/桶，只有批量小于 100 才划算，平时不要用。每开一批要立刻付 $216,500，别把现金花到付不起下一批。

    工厂或仓库菜单 → Quantity 改成 200 → ok

  3. 第 730 天

    订货点 ROP 提到 3200

    游戏里的 FGI = 在途 + 仓库。默认 300 连 7 天卡车期都盖不住，旺季日需求 65 时会连续缺货。ROP 提到 3200 是为了：工厂尽量连轴转、淡季提前屯货、旺季不把生产线停掉。FGI 含在途，所以数字看起来会比仓库库存大一截，这是正常的。

    工厂或仓库菜单 → Order Point 改成 3200 → ok（两处改同一套参数即可）

  4. 第 730 天

    运输保持卡车，不要改成邮寄

    整车 $75/桶、7 天；邮寄 $150/桶、1 天。默认策略用库存和产能换时间，不拿每桶 $75 去买快 6 天。只有仓库眼看要见底、下一批卡车赶不上、而你还愿意少赚时，才临时改 mail 救急。

    Shipping Method 保持 truck: $15,000 / 7 days

  5. 第 820 天

    第 820 天：新产能上线，核对真实需求

    对照 HQ 的 plot demand / plot lost demand。若真实峰值明显高于 65，且现金充裕，可再加 5 产能（最晚大约第 1140 天，再晚回不了本）。若仓库库存已经堆过 4480 且正值淡季（低谷大约第 1094 天），把 ROP 下调 400–600，避免第 1460 天剩货。

    HQ → plot demand / plot lost demand；工厂 → 必要时再 add capacity

  6. 第 912 天

    第 912 天前后：旺季盯缺货，不要停产

    季节高峰附近宁可库存难看，也不要因为害怕持有成本而把 ROP 打回 300。缺一桶大约少赚 $218，而持有一桶一年现金成本大约 $100 + 10% 资金占用。旺季服务水平掉到 90% 以下时，先加 ROP，不要先加邮寄。

    看仓库 plot inventory 和 HQ plot lost demand，ROP 只升不降

  7. 第 1405 天

    大约第 1405 天：停止再投产，把库存卖空

    第 1460 天技术和库存都作废，剩一桶就亏一桶的制造成本。这一天把 Quantity 改 0、Order Point 改 0，工厂不再开新批。在途货继续进仓、继续卖。若停产后仓库仍明显高于剩余需求，说明停早了或产能买多了——下次把停产日往后挪几天。

    工厂 → Order Point = 0，Quantity = 0 → ok。不要拆产能（也拆不了）。

  8. 第 1460 天

    相对默认参数，这套政策大约多留 $1,549,021 现金

    默认 20 产能 / ROP 300 / Q 150 会把两年里大部分旺季需求丢掉。目标不是满足所有需求，而是只做能赚钱的桶：卡车满载、产能贴近均值、淡季屯货、期末清仓。

    Overall Standing 看现金排名；Cash 页核对产能和生产成本流出

上课投影 + 游戏菜单

Round 1 只动这几件事

地图上另外四个地区现在不要建仓建厂。那是后面回合的题，这一回合花出去的钱在 1460 天清零。

生产什么时候会开工

四条同时成立才会开一批：FGI 低于订货点、批量 > 0、现金够付生产和运费、工厂当前空闲。

FGI 不含车间在制品。一批做完才装车，卡车 7 天、邮寄 1 天。设置费 $1,500 + 每桶 $1,000，开工当天连运费一起扣。

所以订货点太低时，工厂会在淡季闲着，旺季再赶已经来不及。订货点太高又没有停产日，期末会剩一堆废料。

不要做的事

不要为峰值买 60–70 产能。多出来的产能一年里有一半时间闲着，回不了 $50,000。

不要把批量留在 150。不满整车等于每桶多付 $25 运费。

不要默认改邮寄。只有仓库见底、卡车赶不上、你愿意少赚 $75 时才救急。

不要在第 1400 天以后还开新批。剩货残值是零。

现金还有 10% 年利率、按日复利。钱放在桶里不生息，但缺货更贵——先算该不该接，再算该不该屯。
